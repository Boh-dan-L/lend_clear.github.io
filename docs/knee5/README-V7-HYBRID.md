# Knee landing V7 — hybrid version

Ця версія поєднує поточний перший екран із перевіреною структурою та стилями попереднього сайту `bohdan.pro/knee/`.

## Змінено

- Перший блок залишено без змін.
- Повернуто блок «Для кого цей курс» у стилі попереднього сайту.
- Повернуто структуру блоку про пасивне лікування, але текст зроблено точнішим і сучаснішим.
- Повернуто старий стиль блоку «Що входить у курс» із конкретними картками.
- Повернуто таймлайн «Структура курсу» без окремого тесту на сайті.
- Окремий блок із 6 бонусними відео збережено та підігнано під темно-синьо-золоту стилістику.
- Окремий блок індивідуальних рекомендацій за 890 грн збережено та стилістично узгоджено.
- Картки вибору формату переведено на стилі попереднього сайту.
- Усі кнопки й посилання на діагностичний тест на лендингу видалено.
- Платіжні `product_id` не змінено: `knee_390` і `knee_890`.

## Перед публікацією

1. Перевірити сторінку на мобільному та desktop.
2. Перевірити обидві кнопки оплати.
3. Перевірити PageView та InitiateCheckout через Meta Test Events.
4. Переконатися, що шляхи до policy/offer відповідають домену розміщення.
